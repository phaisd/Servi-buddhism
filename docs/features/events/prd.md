# Product Requirements Document (PRD)
## Feature: ระบบเข้าร่วมกิจกรรมต่าง ๆ ของนิสิต (Events)

### 1. วัตถุประสงค์ของระบบ (Objective)
เพื่อสร้างพื้นที่ประชาสัมพันธ์และจัดการกิจกรรมของคณะ ให้นิสิตสามารถเข้ามาดูและลงทะเบียนเข้าร่วมได้ พร้อมทั้งอำนวยความสะดวกให้เจ้าหน้าที่เช็คชื่อผู้เข้าร่วมได้จริง

### 2. กลุ่มผู้ใช้งาน (User Personas & Roles)
1. **เจ้าหน้าที่/แอดมิน (Admin/Staff)** - ผู้สร้างกิจกรรมและจัดการผู้เข้าร่วม
2. **นิสิต (Student)** - ผู้ดูกิจกรรมและลงทะเบียนเข้าร่วม (หรือให้เจ้าหน้าที่เพิ่มชื่อให้)

### 3. Functional Requirements & Use Cases

#### 3.1 ฝั่ง Admin (หลังบ้าน)
- **FR-A1: จัดการกิจกรรม (Manage Events)**
  - สร้าง แก้ไข และลบ กิจกรรม (ชื่อ, รายละเอียด, สถานที่, เวลาเริ่ม-จบ, จำนวนที่รับ)
- **FR-A2: จัดการผู้ลงทะเบียน (Manage Registrations)**
  - ดูรายชื่อผู้ลงทะเบียน และเปลี่ยนสถานะ (ลงทะเบียนแล้ว, เข้าร่วมแล้ว, ยกเลิก)

#### 3.2 ฝั่ง Portal (หน้าบ้าน)
- **FR-P1: ดูกิจกรรมและลงทะเบียน (View & Register)**
  - ดูกิจกรรมที่กำลังจะมาถึง
  - (ปัจจุบันอาจเน้นให้ผู้ใช้งานดูรายละเอียดกิจกรรม ส่วนการลงทะเบียนจริงสามารถกดจากหน้าบ้านโดยใช้ฟอร์มง่ายๆ)

### 4. Acceptance Criteria
- [ ] แอดมินสามารถสร้างกิจกรรมใหม่ได้
- [ ] นิสิตสามารถดูรายการกิจกรรมในหน้า Public ได้
- [ ] สามารถบันทึกรายชื่อผู้เข้าร่วมกิจกรรมได้
