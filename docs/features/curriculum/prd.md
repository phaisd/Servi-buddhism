# Product Requirements Document (PRD)
## Feature: ระบบจัดการหลักสูตร (Curriculum Management)

### 1. วัตถุประสงค์ของระบบ (Objective)
เพื่อบริหารจัดการข้อมูลหลักสูตรที่เปิดสอนในคณะพุทธศาสตร์ ตั้งแต่ระดับปริญญาตรี ปริญญาโท และปริญญาเอก ให้บุคคลทั่วไปและว่าที่นักศึกษาสามารถเข้ามาสืบค้นและทำความเข้าใจรายละเอียดของแต่ละหลักสูตรได้

### 2. กลุ่มผู้ใช้งาน (User Personas & Roles)
1. **บุคคลภายนอก/นักศึกษา (Public/Student)** - เข้าใช้งานผ่าน Portal เพื่อดูรายชื่อหลักสูตรที่เปิดสอนและรายละเอียด
2. **เจ้าหน้าที่วิชาการ (Academic Admin)** - เข้าใช้งานผ่าน Admin Console เพื่อเพิ่ม แก้ไขข้อมูลหลักสูตร

### 3. Functional Requirements & Use Cases

#### 3.1 ฝั่ง Portal (หน้าบ้าน)
- **FR-P1: หน้ารายการหลักสูตร (Programs List)**
  - แสดงหลักสูตรทั้งหมดแยกตามระดับปริญญา (ตรี, โท, เอก)
  - แสดงข้อมูลสรุป: ชื่อหลักสูตร, ระยะเวลาเรียน
- **FR-P2: ค้นหาและตัวกรอง (Search & Filter)**
  - ผู้ใช้สามารถกรองหลักสูตรตามระดับปริญญา

#### 3.2 ฝั่ง Admin (หลังบ้าน)
- **FR-A1: จัดการข้อมูลหลักสูตร (Manage Curriculums)**
  - เพิ่ม/แก้ไขข้อมูลหลักสูตร (ชื่อ, ระดับปริญญา, ระยะเวลา, คำอธิบาย, รูปภาพ)
  - ปรับสถานะ เปิดรับสมัคร/ปิดรับสมัคร (ACTIVE/INACTIVE)
  - จัดเรียงลำดับการแสดงผล

### 4. Acceptance Criteria
- [ ] แสดงรายชื่อหลักสูตรที่หน้า Portal แบ่งตามระดับปริญญาได้อย่างถูกต้อง
- [ ] เจ้าหน้าที่สามารถจัดการข้อมูลหลักสูตรผ่านระบบแอดมินได้
- [ ] การแก้ไขข้อมูลมีการบันทึก Audit Log เสมอ
