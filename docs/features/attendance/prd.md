# Product Requirements Document (PRD)
## Feature: ระบบตรวจการเข้าห้องเรียน (Attendance Tracking)

### 1. วัตถุประสงค์ของระบบ (Objective)
เพื่อให้อาจารย์ผู้สอนสามารถจัดการรายวิชาและบันทึกเวลาเรียน (เช็คชื่อ) ของนิสิตได้อย่างสะดวก และติดตามสถิติการเข้าเรียนได้

### 2. กลุ่มผู้ใช้งาน (User Personas & Roles)
1. **อาจารย์ (Teacher / Admin)** - สร้างห้องเรียน, สร้างคาบเรียน, เพิ่มรายชื่อนิสิต, เช็คชื่อ และดูรายงาน
2. **นิสิต (Student)** - (ระยะนี้อาจใช้เพียงดูรายชื่อแบบ Public หรือแอดมินแจ้งผล เนื่องจากเน้นเครื่องมือของอาจารย์เป็นหลัก)

### 3. Functional Requirements & Use Cases

#### 3.1 ฝั่ง Admin/อาจารย์ (หลังบ้าน)
- **FR-A1: จัดการรายวิชา (Manage Classes)**
  - สร้างรายวิชา (รหัสวิชา, ชื่อวิชา, ภาคการศึกษา)
- **FR-A2: จัดการคาบเรียน (Manage Sessions)**
  - สร้างคาบเรียน (วันที่, หัวข้อที่สอน)
- **FR-A3: บันทึกการเข้าเรียน (Record Attendance)**
  - บันทึกรายชื่อนิสิต (รหัสนิสิต, ชื่อ) 
  - เลือกสถานะ (มา, ขาด, สาย, ลา) 

#### 3.2 ฝั่ง Portal (หน้าบ้าน)
- **FR-P1: ดูสถิติ (Public Statistics)**
  - ค้นหาวิชาที่ตนเองเรียน เพื่อดูสถิติการเข้าเรียนของคาบนั้นๆ (แสดงแบบภาพรวม หรือให้นิสิตใส่รหัสผ่าน)
  *หมายเหตุ: ในระยะนี้เราจะเน้นสร้างหน้าแสดงตารางวิชาและคาบเรียนทั้งหมดก่อน*

### 4. Acceptance Criteria
- [ ] อาจารย์สามารถสร้างรายวิชาและคาบเรียนได้
- [ ] สามารถเช็คชื่อนิสิตและบันทึกสถานะลงระบบได้
- [ ] มีตารางสรุปการเข้าเรียนแต่ละคาบ
