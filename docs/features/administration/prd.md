# Product Requirements Document (PRD)
## Feature: ระบบบริหารจัดการ (General Administration & Document Center)

### 1. วัตถุประสงค์ของระบบ (Objective)
เพื่อเป็นศูนย์กลางในการจัดเก็บ เผยแพร่ และดาวน์โหลดเอกสารแบบฟอร์ม คู่มือการปฏิบัติงาน และระเบียบข้อบังคับต่างๆ ของคณะพุทธศาสตร์ สำหรับเจ้าหน้าที่ อาจารย์ และนักศึกษา

### 2. กลุ่มผู้ใช้งาน (User Personas & Roles)
1. **บุคคลทั่วไป / นักศึกษา / เจ้าหน้าที่ (Public & Internal Staff)** - ค้นหาและดาวน์โหลดเอกสารแบบฟอร์มหรือคู่มือ (บางเอกสารอาจสงวนไว้สำหรับบุคลากรภายในเท่านั้น)
2. **เจ้าหน้าที่บริหารทั่วไป (Admin)** - เพิ่มเอกสารใหม่, อัปเดตไฟล์แบบฟอร์ม, จัดหมวดหมู่เอกสาร

### 3. Functional Requirements & Use Cases

#### 3.1 ฝั่ง Portal (หน้าบ้าน)
- **FR-P1: ศูนย์รวมเอกสารดาวน์โหลด (Document Center)**
  - แสดงรายการเอกสารแยกตามหมวดหมู่ (แบบฟอร์ม, คู่มือ, ระเบียบการ)
  - มีช่องค้นหาชื่อเอกสาร
  - แสดงไอคอนประเภทไฟล์ (PDF, Word, Excel) และปุ่มดาวน์โหลด

#### 3.2 ฝั่ง Admin (หลังบ้าน)
- **FR-A1: จัดการแฟ้มเอกสาร (Manage Documents)**
  - อัปโหลดและแนบลิงก์ไฟล์เอกสาร (fileUrl)
  - กำหนดหมวดหมู่ (Category) และสิทธิ์การเข้าถึง (Visibility: สาธารณะ หรือ เฉพาะบุคลากรภายใน)
  - เปลี่ยนสถานะ (Published / Draft)

### 4. Acceptance Criteria
- [ ] เจ้าหน้าที่สามารถอัปโหลดและจัดการลิงก์เอกสารได้ในหลังบ้าน
- [ ] หน้าเว็บ Portal แสดงรายการเอกสารที่ดาวน์โหลดได้ แบ่งตามหมวดหมู่ชัดเจน
- [ ] มีระบบป้องกันไม่ให้ผู้ใช้ทั่วไป (Guest) เห็นเอกสารที่ตั้งค่าเป็น Internal
