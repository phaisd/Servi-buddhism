# Product Requirements Document (PRD)
## Feature: ระบบจัดการบุคลากร (Personnel Management)

### 1. วัตถุประสงค์ของระบบ (Objective)
เพื่อสร้างฐานข้อมูลและระบบแสดงผลทำเนียบบุคลากรของคณะพุทธศาสตร์ แบ่งแยกตามภาควิชาหรือหน่วยงานย่อย (Departments) และประเภทของบุคลากร (สายผู้บริหาร, สายวิชาการ, สายสนับสนุน) ให้บุคคลทั่วไปและนักศึกษาสามารถสืบค้นและติดต่อได้ง่าย

### 2. กลุ่มผู้ใช้งาน (User Personas & Roles)
1. **บุคคลภายนอก/นักศึกษา (Public/Student)** - เข้าใช้งานผ่าน Portal เพื่อดูทำเนียบบุคลากรและข้อมูลติดต่อ
2. **เจ้าหน้าที่บุคคล (HR Admin)** - เข้าใช้งานผ่าน Admin Console เพื่อเพิ่ม แก้ไข และลบข้อมูลบุคลากร รวมถึงจัดการโครงสร้างภาควิชา

### 3. Functional Requirements & Use Cases

#### 3.1 ฝั่ง Portal (หน้าบ้าน)
- **FR-P1: ทำเนียบบุคลากร (Staff Directory)**
  - ผู้ใช้สามารถดูรายชื่อบุคลากรทั้งหมด โดยมีการแบ่งกลุ่มตามภาควิชา (Departments)
  - แสดงข้อมูลพื้นฐาน: รูปภาพ, ชื่อ-สกุล, ตำแหน่งทางวิชาการ/บริหาร, และอีเมลติดต่อ
- **FR-P2: ค้นหาและกรอง (Search & Filter)**
  - ค้นหาบุคลากรจากชื่อ หรือกรองตามหน่วยงาน/ประเภทบุคลากร

#### 3.2 ฝั่ง Admin (หลังบ้าน)
- **FR-A1: จัดการโครงสร้างหน่วยงาน (Manage Departments)**
  - เพิ่ม/แก้ไข/ลบ หน่วยงานหรือภาควิชาภายในคณะ
- **FR-A2: จัดการข้อมูลบุคลากร (Manage Personnel)**
  - เพิ่มข้อมูลบุคลากร (ชื่อ, ตำแหน่ง, รูปภาพ, สังกัดภาควิชา, ช่องทางติดต่อ, สถานะ Active/Inactive)
  - กำหนดประเภทของบุคลากร (เช่น ผู้บริหาร, สายวิชาการ)
  - จัดเรียงลำดับการแสดงผล (Display Order) ในหน้าเว็บ

### 4. Acceptance Criteria
- [ ] แสดงรายชื่อบุคลากรที่หน้า Portal ตามหมวดหมู่ได้ถูกต้อง
- [ ] เจ้าหน้าที่สามารถสร้างหน่วยงาน (Department) และเพิ่มบุคลากรเข้าหน่วยงานนั้นได้
- [ ] การแก้ไขข้อมูลบุคลากรมีระบบ Audit Log บันทึก
- [ ] บุคลากรที่มีสถานะ Inactive จะไม่แสดงในหน้า Portal
